# First Light

A location-aware dawn chorus that turns recently reported birds near you into an ambient soundscape shaped by place and season.

## About

First Light begins with a location. It looks at recent nearby bird reports, selects five species, pairs them with bird-song recordings, and layers those voices into a small dawn chorus.

The experience is designed to feel less like browsing a bird database and more like hearing a morning that belongs to a particular place.

## Features

- Location-based bird selection
- Five-species dawn chorus generation
- Recent observation weighting
- Bird-song playback and layered Web Audio
- Individual mute controls
- Replay and shuffle controls
- Ambient Mode with a changing dawn-sky interface
- Shareable postcard-style session summary

## Data and audio

- eBird data for recent local observations
- Xeno-canto recordings for bird vocalizations
- Browser geolocation for location-aware sessions

## Stack

- JavaScript
- Web Audio
- Geolocation APIs
- eBird and Xeno-canto data
- Static browser-based frontend
